# jonathan-erb.github.io

Personal portfolio website hosted on GitHub Pages.

## About
This is a professional portfolio website showcasing skills, projects, and contact information.

## Features
- Responsive design that works on desktop, tablet, and mobile devices
- Clean and modern UI
- Sections for About, Skills, Projects, and Contact
- Smooth scrolling navigation
- SEO-friendly with proper meta tags

## Customization
To customize this portfolio for your needs:
1. Edit `index.html` to update your personal information
2. Modify the skills, projects, and contact links
3. Adjust colors and styles in `styles.css` to match your preference

## Local Development
To view the website locally:
```bash
python3 -m http.server 8080
```
Then visit `http://localhost:8080` in your browser.

## Deployment
This website is automatically deployed to GitHub Pages at: https://jonathan-erb.github.io/
